# Portfólio — Marcio (UVV, Sistemas de Informação)

Páginas: `index.html` (Home), `curriculo.html`, `github.html`, `servicos.html`, `contato.html`.

## Antes de publicar, edite
- `assets/img/foto.jpg` → troque pela sua foto (mesmo nome).
- Procure por `[EDITAR]` e `SEU-USUARIO` nos arquivos .html e substitua.
- Troque `seuemail@email.com` pelo seu e-mail.

## Publicar no GitHub Pages
1. Crie um repositório público e envie todos os arquivos, mantendo as pastas.
2. Settings → Pages → Branch `main`, pasta `/ (root)` → Save.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
